# Cars & Animals — Streetcars SU × Paramaribo Zoo

Static event website for the Suriname jungle car event at Paramaribo Zoo.

## Netlify
This repository is ready for Netlify.

- Build command: leave empty
- Publish directory: .
- Netlify Forms: enabled for the car placement application form
- Success page: /thanks.html

The included netlify.toml already sets the publish directory and basic security headers.

## Update before launch
In index.html, replace the placeholders once confirmed:

- Date: currently “Binnenkort bekend”
- Entree: currently “SRD —”
- Car placement: currently “SRD —”

- index.html — main event page
